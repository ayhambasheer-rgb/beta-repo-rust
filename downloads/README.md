# Ledger for Mac download

Open [Ledger-for-Mac.zip](Ledger-for-Mac.zip) and click **Download raw file** (the download arrow). If GitHub asks you to sign in, use the account that can access this repository.

1. Install and open [Docker Desktop](https://www.docker.com/products/docker-desktop/), then complete its welcome screens.
2. Unzip the download and move the whole **Ledger for Mac** folder into Documents.
3. Double-click **Start Ledger.command**. The first start downloads and builds the app and may take 10–20 minutes or longer.
4. Choose your login when prompted. Your browser will open the app.

The package keeps Rust, React, and PostgreSQL. It also includes stop and backup launchers and **START HERE - macOS.txt** with troubleshooting instructions. No test records or real credentials are included.

The container startup, browser workflows, restart persistence, and backup restoration passed validation in the cloud machine. Native macOS Finder execution and Apple silicon builds have not been tested there.
